# Erciyes Uçuşu

Kayseri temalı, özgün bir mobil arcade oyunu. Oyuncu, kendi karakter görseliyle uçarken engeller arasından geçer.

## Teknoloji
- Native Android / Kotlin
- Özel Canvas tabanlı oyun döngüsü
- Offline çalışma
- SharedPreferences ile yüksek skor

## Proje
Bu repo Android Studio ile açılabilir. `app/src/main/assets/` altında oyun görselleri bulunur.

## Özellikler
- Dokunarak yükselme ve yer çekimi
- Rastgele engel boşlukları
- Skor ve yüksek skor
- Menü / oyun / oyun sonu ekranları
- Ses aç/kapat
- Kayseri, Erciyes ve şehir silüeti teması

## APK
Android Studio'da `Build > Build APK(s)` ile APK üretilebilir.
